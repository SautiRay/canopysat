{% if lang == 'fr' %}2. Pipeline de traitement{% else %}2. Processing Pipeline{% endif %}

STEP 1
{% if lang == 'fr' %}Sélection de la zone{% else %}Zone selection{% endif %}
{% if lang == 'fr' %}L'utilisateur définit une zone GPS circulaire (1-100km de rayon). CanopySat crée un buffer géospatial et le transmet à Google Earth Engine.{% else %}The user defines a circular GPS zone (1-100km radius). CanopySat creates a geospatial buffer and sends it to Google Earth Engine.{% endif %}
STEP 2
{% if lang == 'fr' %}Composite sans nuages{% else %}Cloud-free composite{% endif %}
{% if lang == 'fr' %}CanopySat génère un composite médian des images Sentinel-2 des 12 derniers mois, en excluant les pixels nuageux (filtre QA60). Cela garantit une analyse basée sur les données les plus récentes disponibles.{% else %}CanopySat generates a median composite of Sentinel-2 images from the last 12 months, excluding cloudy pixels (QA60 filter). This ensures analysis based on the most recent available data.{% endif %}
STEP 3
{% if lang == 'fr' %}Calcul des indices{% else %}Index calculation{% endif %}
{% if lang == 'fr' %}NDVI (Normalized Difference Vegetation Index) = (NIR - RED) / (NIR + RED). Valeurs entre -1 et 1, où >0.5 indique une végétation dense et saine. Sentinel-1 VV/VH backscatter pour la structure forestière sous couvert nuageux.{% else %}NDVI (Normalized Difference Vegetation Index) = (NIR - RED) / (NIR + RED). Values between -1 and 1, where >0.5 indicates dense healthy vegetation. Sentinel-1 VV/VH backscatter for forest structure under cloud cover.{% endif %}
STEP 4
{% if lang == 'fr' %}Tendance historique{% else %}Historical trend{% endif %}
{% if lang == 'fr' %}CanopySat calcule la tendance NDVI sur 3 ans, 10 ans et 40 ans (depuis 1984) en utilisant Landsat 4/5/8/9. Une tendance positive indique une régénération forestière, une tendance négative indique une dégradation.{% else %}CanopySat calculates NDVI trend over 3 years, 10 years and 40 years (since 1984) using Landsat 4/5/8/9. A positive trend indicates forest regeneration, a negative trend indicates degradation.{% endif %}
STEP 5
{% if lang == 'fr' %}Hauteur canopée GEDI{% else %}GEDI canopy height{% endif %}
{% if lang == 'fr' %}NASA GEDI LiDAR (Global Ecosystem Dynamics Investigation) mesure la hauteur de la canopée forestière depuis la Station Spatiale Internationale à 25m de résolution. CanopySat extrait la hauteur moyenne pour la zone analysée.{% else %}NASA GEDI LiDAR (Global Ecosystem Dynamics Investigation) measures forest canopy height from the International Space Station at 25m resolution. CanopySat extracts the mean height for the analyzed zone.{% endif %}
STEP 6
{% if lang == 'fr' %}Calcul du Forest Integrity Score{% else %}Forest Integrity Score calculation{% endif %}
{% if lang == 'fr' %}Tous les indicateurs sont combinés en un score unique 0-100. Voir la page Forest Integrity Score pour le détail de l'algorithme.{% else %}All indicators are combined into a single 0-100 score. See the Forest Integrity Score page for algorithm details.{% endif %}
{% if lang == 'fr' %}Toutes les analyses sont traitées via Google Earth Engine avec un compte de service dédié. Les données satellites sont publiques (ESA Copernicus, NASA EOSDIS).{% else %}All analyses are processed via Google Earth Engine with a dedicated service account. Satellite data is publicly available (ESA Copernicus, NASA EOSDIS).{% endif %}

{% if lang == 'fr' %}4. Calcul Biomasse & Carbone{% else %}4. Biomass & Carbon Calculation{% endif %}

{% if lang == 'fr' %} CanopySat calcule la biomasse aérienne (AGB) en utilisant la hauteur de canopée NASA GEDI LiDAR avec des équations allométriques spécifiques par biome, validées contre GFW/WHRC, FAO FRA 2020 et ESA CCI Biomass (erreur moyenne 0.8%). {% else %} CanopySat calculates above-ground biomass (AGB) using NASA GEDI LiDAR canopy height with biome-specific allometric equations, validated against GFW/WHRC, FAO FRA 2020 and ESA CCI Biomass (mean error 0.8%). {% endif %}

{% if lang == 'fr' %}# Formule allométrique par biome (Chave 2014 + Potapov 2021){% else %}# Biome-specific allometric formula (Chave 2014 + Potapov 2021){% endif %}
AGB (t/ha) = k × H²

{% if lang == 'fr' %}# Coefficients k validés :{% else %}# Validated coefficients k:{% endif %}
Tropical (Amazon, Congo): k = 0.68
Tropical SE Asia (Borneo): k = 1.17
Subtropical: k = 0.75
Temperate: k = 0.88
Boreal: k = 0.90

{% if lang == 'fr' %}# Calcul carbone IPCC 2006/2019 Tier 1 :{% else %}# IPCC 2006/2019 Tier 1 carbon calculation:{% endif %}
BGB = AGB × 0.26 {% if lang == 'fr' %}# ratio racines/tiges{% else %}# root-to-shoot ratio{% endif %}
Carbon (t C/ha) = (AGB + BGB) × 0.47
CO2 (t CO2/ha) = Carbon × 3.67

{% if lang == 'fr' %}5. Suitabilité Climatique des Espèces — Méthode BEA{% else %}5. Species Climate Suitability — BEA Method{% endif %}

{% if lang == 'fr' %}Bioclimatic Envelope Assessment (BEA){% else %}Bioclimatic Envelope Assessment (BEA){% endif %}

{% if lang == 'fr' %} CanopySat utilise une approche d'évaluation des enveloppes bioclimatiques (BEA) pour prédire la suitabilité climatique des espèces forestières en 2050. Cette méthode est cohérente avec les résultats des modèles MaxEnt complets pour les tendances générales (cf. études publiées sur Ceiba pentandra, SSP2-4.5, Frontiers in Forests 2026). {% else %} CanopySat uses a Bioclimatic Envelope Assessment (BEA) approach to predict climate suitability of forest species in 2050. This method is consistent with full MaxEnt model results for general trends (cf. published studies on Ceiba pentandra, SSP2-4.5, Frontiers in Forests 2026). {% endif %}

{% if lang == 'fr' %}Limitations importantes{% else %}Important limitations{% endif %}
  • {% if lang == 'fr' %}Température estimée depuis la latitude (approximation bioclimatique) — pas de données de terrain{% else %}Temperature estimated from latitude (bioclimatic approximation) — no field data{% endif %}
  • {% if lang == 'fr' %}Modèle simplifié — ne prend pas en compte l'altitude, le type de sol ou la compétition interspécifique{% else %}Simplified model — does not account for altitude, soil type or interspecific competition{% endif %}
  • {% if lang == 'fr' %}Basé sur 100 occurrences GBIF par espèce — peut manquer de représentativité pour les espèces rares{% else %}Based on 100 GBIF occurrences per species — may lack representativeness for rare species{% endif %}
  • {% if lang == 'fr' %}Ensemble de 5 modèles CMIP6 (ACCESS-CM2, MIROC6, MPI-ESM1-2-HR, GFDL-ESM4, BCC-CSM2-MR) — un ensemble plus large (10+ modèles) donnerait encore plus de robustesse{% else %}5-model CMIP6 ensemble (ACCESS-CM2, MIROC6, MPI-ESM1-2-HR, GFDL-ESM4, BCC-CSM2-MR) — a larger ensemble (10+ models) would provide even more robustness{% endif %}
