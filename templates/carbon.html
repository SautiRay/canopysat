{% if lang == 'fr' %}Calcul CO2 — Méthodologie IPCC{% else %}CO2 Calculation — IPCC Methodology{% endif %}

{% if lang == 'fr' %}CanopySat calcule automatiquement le CO2 séquestré pour chaque zone analysée en utilisant la méthodologie standard IPCC.{% else %}CanopySat automatically calculates the CO2 sequestered for each analyzed zone using the standard IPCC methodology.{% endif %}

AGB (Above-Ground Biomass) → measured via NASA GEDI LiDAR + Sentinel-2 BGB (Below-Ground Biomass) = AGB × 0.26 (IPCC root-to-shoot ratio) Total Biomass = AGB + BGB Carbon (t C/ha) = Total Biomass × 0.47 (carbon fraction) CO2 (t CO2/ha) = Carbon × 3.67 (molecular weight CO2/C) Total CO2 (t) = CO2/ha × Zone area (ha) Carbon credit value (EUR) = Total CO2 × 15 EUR/tonne

{% if lang == 'fr' %}Source: IPCC Guidelines for National Greenhouse Gas Inventories (2006, 2019 refinement). Prix carbone: marché volontaire 2024.{% else %}Source: IPCC Guidelines for National Greenhouse Gas Inventories (2006, 2019 refinement). Carbon price: voluntary market 2024.{% endif %}

CanopySat provides the independent, continuous satellite monitoring layer that supports this process.{% endif %}
