SCIENCE · LIMITATIONS

{% if lang == 'fr' %}Limitations{% else %}Limitations{% endif %}

{% if lang == 'fr' %}La transparence scientifique est essentielle. Voici ce que CanopySat ne peut pas faire — et ce qu'il peut faire.{% else %}Scientific transparency is essential. Here is what CanopySat cannot do — and what it can do.{% endif %}

{% if lang == 'fr' %}Limitations connues{% else %}Known limitations{% endif %}

{% if lang == 'fr' %}Couverture nuageuse persistante{% else %}Persistent cloud cover{% endif %}
{% if lang == 'fr' %}Dans les zones tropicales avec une couverture nuageuse permanente (ex: certaines zones de l'Amazonie occidentale), le composite Sentinel-2 peut manquer de données récentes. CanopySat utilise un composite 12 mois pour minimiser ce problème, mais des zones très nuageuses peuvent avoir des données moins récentes.{% else %}In tropical zones with permanent cloud cover (e.g. some areas of the western Amazon), the Sentinel-2 composite may lack recent data. CanopySat uses a 12-month composite to minimize this issue, but heavily cloudy zones may have less recent data.{% endif %}
{% if lang == 'fr' %}Résolution spatiale{% else %}Spatial resolution{% endif %}
{% if lang == 'fr' %}La résolution minimale est 10m (Sentinel-2). Des perturbations forestières inférieures à 10m × 10m peuvent ne pas être détectées. Pour des zones très petites, les résultats peuvent être moins précis.{% else %}The minimum resolution is 10m (Sentinel-2). Forest disturbances smaller than 10m × 10m may not be detected. For very small zones, results may be less precise.{% endif %}
{% if lang == 'fr' %}Zone d'analyse vs forêt entière{% else %}Analysis zone vs entire forest{% endif %}
{% if lang == 'fr' %}CanopySat analyse une zone GPS spécifique — pas la forêt entière. Un score de 50km de rayon dans l'Amazonie représente 7,854 km² — une fraction de l'Amazonie totale (5.5M km²). Utiliser des zones bien ciblées pour des résultats pertinents.{% else %}CanopySat analyzes a specific GPS zone — not the entire forest. A 50km radius score in the Amazon represents 7,854 km² — a fraction of the total Amazon (5.5M km²). Use well-targeted zones for relevant results.{% endif %}
{% if lang == 'fr' %}GEDI LiDAR — couverture partielle{% else %}GEDI LiDAR — partial coverage{% endif %}
{% if lang == 'fr' %}NASA GEDI LiDAR couvre les latitudes entre 51.6°S et 51.6°N — les forêts boréales nordiques (Canada >51.6°N, Sibérie >51.6°N) n'ont pas de données GEDI. Dans ces zones, la hauteur de canopée est estimée par d'autres méthodes.{% else %}NASA GEDI LiDAR covers latitudes between 51.6°S and 51.6°N — northern boreal forests (Canada >51.6°N, Siberia >51.6°N) have no GEDI data. In these zones, canopy height is estimated by other methods.{% endif %}
{% if lang == 'fr' %}Délai de mise à jour{% else %}Update delay{% endif %}
{% if lang == 'fr' %}CanopySat utilise les données Sentinel-2 des 12 derniers mois. Des événements très récents (moins de 2 semaines) peuvent ne pas encore être intégrés dans l'analyse.{% else %}CanopySat uses Sentinel-2 data from the last 12 months. Very recent events (less than 2 weeks) may not yet be integrated into the analysis.{% endif %}

{% if lang == 'fr' %}Limitations — Suitabilité Climatique des Espèces (BEA){% else %}Limitations — Species Climate Suitability (BEA){% endif %}

{% if lang == 'fr' %}Modèle simplifié — pas MaxEnt complet{% else %}Simplified model — not full MaxEnt{% endif %}
{% if lang == 'fr' %}CanopySat utilise une approche d'enveloppes bioclimatiques (BEA) basée sur la distribution GBIF des espèces. Cette méthode est cohérente avec MaxEnt pour les tendances générales mais n'est pas équivalente à un modèle MaxEnt complet qui intègre toutes les variables environnementales.{% else %}CanopySat uses a Bioclimatic Envelope Assessment (BEA) approach based on GBIF species distribution. This method is consistent with MaxEnt for general trends but is not equivalent to a full MaxEnt model integrating all environmental variables.{% endif %}
{% if lang == 'fr' %}Température estimée depuis la latitude{% else %}Temperature estimated from latitude{% endif %}
{% if lang == 'fr' %}La tolérance thermique des espèces est estimée depuis la latitude de leurs occurrences GBIF via la formule : T = 27 - |lat| × 0.52°C. Cette approximation ne prend pas en compte l'altitude, les microclimats ou les adaptations locales.{% else %}Species thermal tolerance is estimated from the latitude of their GBIF occurrences via the formula: T = 27 - |lat| × 0.52°C. This approximation does not account for altitude, microclimates or local adaptations.{% endif %}
{% if lang == 'fr' %}Variables non prises en compte{% else %}Variables not accounted for{% endif %}
{% if lang == 'fr' %}Le modèle BEA actuel ne prend pas en compte : l'altitude, le type de sol, la compétition interspécifique, la dispersion des espèces, ni les événements extrêmes (sécheresses, incendies). Ces facteurs peuvent influencer significativement la suitabilité réelle.{% else %}The current BEA model does not account for: altitude, soil type, interspecific competition, species dispersal, or extreme events (droughts, fires). These factors can significantly influence actual suitability.{% endif %}
{% if lang == 'fr' %}Un seul modèle climatique{% else %}Single climate model{% endif %}
{% if lang == 'fr' %}Les projections 2050 utilisent un ensemble de 5 modèles CMIP6 (ACCESS-CM2, MIROC6, MPI-ESM1-2-HR, GFDL-ESM4, BCC-CSM2-MR) sous le scénario SSP2-4.5. La moyenne de l'ensemble réduit l'incertitude par rapport à un modèle unique.{% else %}2050 projections use a 5-model CMIP6 ensemble (ACCESS-CM2, MIROC6, MPI-ESM1-2-HR, GFDL-ESM4, BCC-CSM2-MR) under the SSP2-4.5 scenario. The ensemble mean reduces uncertainty compared to a single model.{% endif %}
{% if lang == 'fr' %}Cohérence avec MaxEnt confirmée{% else %}Consistency with MaxEnt confirmed{% endif %}
{% if lang == 'fr' %}Des comparaisons avec des études MaxEnt publiées (ex: Ceiba pentandra, Frontiers in Forests 2026) montrent que la méthode BEA de CanopySat produit des tendances générales cohérentes. Elle est adaptée à une évaluation rapide à l'échelle mondiale.{% else %}Comparisons with published MaxEnt studies (e.g. Ceiba pentandra, Frontiers in Forests 2026) show that CanopySat's BEA method produces consistent general trends. It is suitable for rapid global-scale assessment.{% endif %}
