{% if lang == 'fr' %}Forest Integrity Score{% else %}Forest Integrity Score{% endif %}

{% if lang == 'fr' %} Un score composite 0-100 qui intègre 6 sources satellites, un classifieur Random Forest ML entraîné sur ESA WorldCover + Hansen GFW, et une analyse par Intelligence Artificielle pour quantifier l'intégrité d'une zone forestière. {% else %} A composite 0-100 score integrating 6 satellite sources, a Random Forest ML classifier trained on ESA WorldCover + Hansen GFW, and Artificial Intelligence analysis to quantify forest zone integrity. {% endif %}

77
{% if lang == 'fr' %}EXEMPLE — FORÊT AMAZONIENNE · OCTOBRE 2026{% else %}EXAMPLE — AMAZON RAINFOREST · OCTOBER 2026{% endif %}

{% if lang == 'fr' %}Score base satellites: 80/100 · Pénalité RF déforestation: -3 pts (4.8% perte 2021-2026) · Score final: 77/100 Good Forest{% else %}Base satellite score: 80/100 · RF deforestation penalty: -3 pts (4.8% loss 2021-2026) · Final score: 77/100 Good Forest{% endif %}

{% if lang == 'fr' %}1. Formule de calcul{% else %}1. Calculation formula{% endif %}

{% if lang == 'fr' %}# Formule de base (avant correction RF){% else %}# Base formula (before RF correction){% endif %}
Score = pts_NDVI + pts_Trend + pts_Cover + pts_Radar + pts_Fire
Score_max = 25 + 25 + 25 + 15 + 10 = 100 points

{% if lang == 'fr' %}# Correction Random Forest (pénalité déforestation){% else %}# Random Forest correction (deforestation penalty){% endif %}
{% if lang == 'fr' %}if déforestation RF > 15%: Score -= 20{% else %}if RF deforestation > 15%: Score -= 20{% endif %}
{% if lang == 'fr' %}if déforestation RF > 10%: Score -= 15{% else %}if RF deforestation > 10%: Score -= 15{% endif %}
{% if lang == 'fr' %}if déforestation RF > 5%: Score -= 8{% else %}if RF deforestation > 5%: Score -= 8{% endif %}
{% if lang == 'fr' %}if déforestation RF > 2%: Score -= 3{% else %}if RF deforestation > 2%: Score -= 3{% endif %}
{% if lang == 'fr' %}if dégradation RF > 20%: Score -= 10{% else %}if RF degradation > 20%: Score -= 10{% endif %}
{% if lang == 'fr' %}if dégradation RF > 10%: Score -= 6{% else %}if RF degradation > 10%: Score -= 6{% endif %}
{% if lang == 'fr' %}if dégradation RF > 5%: Score -= 3{% else %}if RF degradation > 5%: Score -= 3{% endif %}

Final Score = max(0, Score - RF_penalty)

{% if lang == 'fr' %}7. Limitations{% else %}7. Limitations{% endif %}

{% if lang == 'fr' %}Points importants{% else %}Important points{% endif %}

  • {% if lang == 'fr' %}Le score représente une zone d'analyse (1-100km) — pas la forêt entière{% else %}The score represents an analysis zone (1-100km) — not the entire forest{% endif %}
  • {% if lang == 'fr' %}GEDI LiDAR limité au-dessus de 51.6° de latitude{% else %}GEDI LiDAR limited above 51.6° latitude{% endif %}
  • {% if lang == 'fr' %}{% if lang == 'fr' %}Le classifieur RF est entraîné sur 100 points/classe{% else %}RF classifier trained on 100 points/class{% endif %} — un entraînement plus large améliorerait la précision{% else %}RF classifier trained on 100 points/class — larger training would improve accuracy{% endif %}
  • {% if lang == 'fr' %}L'IA analyse des données spectrales — pas des images directes{% else %}AI analyzes spectral data — not direct images{% endif %}
  • {% if lang == 'fr' %}La déforestation RF couvre dynamiquement les 5 dernières années (2021-2026) — mise à jour automatique chaque année{% else %}RF deforestation dynamically covers the last 5 years (2021-2026) — updated automatically each year{% endif %}
